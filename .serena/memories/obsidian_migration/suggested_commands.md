# Suggested commands
- `python3 scripts/parse_clippings.py` — process `My Clippings.txt` into raw book notes.
- `python3 scripts/promote_kindle.py <raw_note> <target_note> <title> <author>` — promote a raw book note into a styled vault note.
- `./scripts/install-autopull-systemd.sh` — install user autopull timer.
- `./scripts/install-vps-autopull-systemd.sh` — install VPS-aware autopull + docker refresh.
- `./install.sh` — Linux/macOS bootstrap for config repo.
- `./install.ps1` — Windows bootstrap.
- `git status` — quick sanity check after edits.
- `python3 -m py_compile scripts/*.py` — quick syntax check for Python edits.
